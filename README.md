# 오늘의 발성 연습 (Voice Training PWA)

8주 발성 훈련 프로그램(1~4주: 발성 안정화·저음화 / 5~8주: 허스키·샤우팅)을 위한
"오늘의 연습" 안내 + 완료 체크 모바일 웹앱입니다. 별도 스토어 등록 없이,
GitHub Pages로 무료 배포한 뒤 휴대폰 브라우저에서 "홈 화면에 추가"하면
앱처럼 아이콘을 눌러 실행할 수 있습니다 (PWA, Progressive Web App).

## 폴더 구성

```
app/
 ├─ index.html      메인 화면 (UI + 8주 프로그램 데이터 + 로직 포함)
 ├─ manifest.json   PWA 설정 (앱 이름, 아이콘, 테마 색상)
 ├─ sw.js           오프라인 캐싱을 위한 서비스 워커
 ├─ icons/
 │   ├─ icon-192.png
 │   └─ icon-512.png
 └─ README.md       (이 파일)
```

## GitHub Pages로 배포하는 방법 (약 5분)

1. github.com 에 로그인 후, 우측 상단 **+ → New repository** 클릭
2. 저장소 이름을 정하고(예: `voice-training-app`) **Create repository** 클릭
3. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
4. 이 `app` 폴더 안의 모든 파일과 폴더(`index.html`, `manifest.json`, `sw.js`, `icons/` 전체)를
   그대로 끌어다 놓고 **Commit changes** 클릭
   - (Git을 사용할 줄 안다면 터미널에서 다음과 같이 올려도 됩니다)
     ```
     git init
     git add .
     git commit -m "voice training app"
     git branch -M main
     git remote add origin https://github.com/<내계정>/voice-training-app.git
     git push -u origin main
     ```
5. 저장소 상단 메뉴에서 **Settings → Pages** 로 이동
6. "Build and deployment" 항목에서 **Source: Deploy from a branch** 선택,
   **Branch: main** / **Folder: / (root)** 로 설정 후 **Save**
7. 1~2분 기다리면 상단에 다음과 같은 배포 주소가 표시됩니다.
   `https://<내계정>.github.io/voice-training-app/`
8. 휴대폰 브라우저(Safari 또는 Chrome)로 위 주소에 접속합니다.

## 휴대폰에 앱처럼 설치하기

- **iPhone(Safari)**: 주소 접속 → 하단 공유 버튼(⬆️) → **홈 화면에 추가**
- **Android(Chrome)**: 주소 접속 → 우측 상단 메뉴(⋮) → **홈 화면에 추가** 또는 화면 하단에 뜨는 "앱 설치" 배너 클릭

설치 후에는 홈 화면 아이콘을 눌러 일반 앱처럼 실행되며, 오늘 날짜에 해당하는
연습 내용이 자동으로 표시됩니다.

## 앱 사용법

- 처음 실행 시 프로그램을 시작할 날짜를 선택하면, 이후 매일 그 날짜 기준으로
  몇 주차·몇 일째인지 자동 계산해 그날의 연습(효과/방법/소요시간) 또는 휴식일을 보여줍니다.
- 연습을 마치면 "오늘 연습 완료 체크" 버튼을 눌러 기록합니다. 상단의 진행 현황 스트립에서
  최근 완료 여부를 한눈에 볼 수 있습니다.
- 우측 상단 "설정" 버튼으로 시작일을 다시 설정할 수 있습니다.
- 6~8주차(허스키·샤우팅)에는 안전을 위해 자동으로 휴식일이 포함되어 있으며,
  휴식일에는 가벼운 워밍업만 하도록 안내합니다.

## 알림(리마인더)에 대한 참고사항

이 앱은 앱을 열었을 때 오늘의 연습 내용을 보여주는 방식입니다. 앱을 닫아둔 상태에서도
휴대폰이 매일 알림을 띄우게 하려면(진짜 "푸시 알림"), 별도의 푸시 서버 연동이 필요하고
iPhone Safari의 경우 홈 화면에 추가된 PWA에서도 지원이 제한적입니다. 간단한 대안으로는
휴대폰의 기본 "미리 알림/알람" 앱에 "발성 연습 체크하기"를 매일 반복 알림으로 등록해
이 앱을 여는 습관을 만드는 방법을 추천합니다.

## 데이터 저장 위치

모든 진행 기록(시작일, 완료 체크)은 브라우저의 로컬 저장소(localStorage)에 휴대폰 안에만
저장됩니다. 외부 서버로 전송되지 않으며, 브라우저 데이터를 삭제하면 기록도 함께 사라집니다.

## 프로그램 코드를 직접 수정하고 싶다면

`index.html` 안의 `PROGRAM` 배열(자바스크립트)에 각 주차별 제목, 효과, 연습 방법, 소요시간,
휴식일이 정의되어 있습니다. 이 배열의 텍스트를 원하는 대로 수정하면 앱 내용을 바로 바꿀 수 있습니다.
